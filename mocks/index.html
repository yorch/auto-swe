The shift

The engine was always the product.

auto-swe already runs every job as a configurable, versioned DAG. The pivot makes that engine first-class and turns every domain into reusable library content — Agents, Templates, Skills & Connections composed into workflows. SWE is just the first set seeded in.

The crowded part — "compose agent steps" — isn't the moat. The moat is everything around it: durability, governance, security, memory, and cost. SWE becomes the flagship proof, not the ceiling.

Reusable libraries

Compose, don't fork.

Everything reusable lives in versioned libraries — Agents, Templates, Skills, Connections. Reference an Agent from any number of workflows; customize per team or template with overrides, never copies.

The engine owns the mechanisms (review network, fan-out, scanning, memory); the libraries hold the content. SWE is just the first set seeded in — no privileged status, fully editable.
